# Expense Tracker

A simple Python-based expense tracker for managing, storing, and analyzing personal expenses using core Python concepts.

## Features

* Add new expenses
* View all recorded expenses
* Calculate total expenses
* View category-wise spending
* Search expenses by category
* Delete expenses
* Automatically save expenses to a JSON file
* Load previously saved expenses when the program starts
* Basic input validation and error handling

## Technologies Used

* Python
* JSON
* File Handling
* Object-Oriented Programming

## How to Run

1. Make sure Python is installed on your system.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python main.py
```

## Data Storage

The application stores expense records in `expenses.json`.

The file is automatically created and updated when expenses are added or deleted.
